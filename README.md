# RemoteConnect

Удалённый доступ к компьютеру друга — как AnyDesk, но напрямую между двумя ПК, без сторонних серверов.
Видно экран, работают мышь, клавиатура, общий буфер обмена (текст, картинки и файлы) и чат, трафик зашифрован, а без подтверждения на управляемом ПК сессия не начнётся.

- Спецификация: [specs/spec.md](specs/spec.md), файлы через буфер обмена — [specs/spec-file-clipboard.md](specs/spec-file-clipboard.md), чат — [specs/spec-chat.md](specs/spec-chat.md), качество под канал — [specs/spec-v0.5.md](specs/spec-v0.5.md)
- План реализации и статус: [specs/plan.md](specs/plan.md), [specs/plan-file-clipboard.md](specs/plan-file-clipboard.md), [specs/plan-chat.md](specs/plan-chat.md), [specs/plan-v0.5.md](specs/plan-v0.5.md)

## Как это устроено в двух словах

Один компьютер — **хост**: он «ждёт подключения» на TCP-порту (по умолчанию 47800) и сам открывает этот порт на роутере через UPnP.
Второй — **клиент**: подключается к хосту по адресу `IP:порт` и паролю.

Кто кем управляет — выбирает клиент при подключении, независимо от того, кто хост:

| На вкладке «Подключиться» выбрано | Кто управляет | Где появится запрос «Разрешить?» и красная плашка |
|---|---|---|
| Управлять удалённым ПК | клиент управляет хостом | на хосте |
| Разрешить управление моим ПК | хост управляет клиентом | на клиенте |

Поэтому достаточно, чтобы **порт был открыт только у одного из вас**.

## Тест с другом — пошагово

Нужен один файл `RemoteConnect.exe` (собирается командой ниже, ~64 МБ, .NET ставить не нужно). Отправьте его другу.

> При первом запуске Windows SmartScreen может предупредить о неизвестном издателе (файл не подписан):
> «Подробнее» → «Выполнить в любом случае».

### Вы (хост)

1. **VPN:** если он включён, приложение предупредит. Входящие подключения при VPN могут не дойти: это зависит от его настроек. Если друг не может подключиться, выключите VPN на время сессии. Клиенту, который подключается, VPN не мешает.
2. Запустите `RemoteConnect.exe`, впишите своё имя вверху.
3. Вкладка **«Хост»** → **«Начать ожидание»**.
4. Если Windows спросит про брандмауэр — **разрешите доступ** (отметьте тип сети, в которой работает ПК; для дома — «Частные сети»).
5. Дождитесь статуса. Возможные варианты:
   - **«Готово» / «Порт открыт на роутере через UPnP»** — всё хорошо.
   - **«Роутер с поддержкой UPnP не найден»** — включите UPnP в настройках роутера (обычно раздел «NAT» / «UPnP») и перезапустите ожидание. Или пробросьте TCP-порт 47800 на локальный адрес ПК вручную (адрес — в «Дополнительно»).
   - **«Серый IP (CGNAT)»** — из интернета к вам не подключиться. Поменяйтесь: хостом будет друг.
6. Нажмите **«Скопировать»** и отправьте другу (там адрес, одноразовый пароль и код хоста).

### Друг (клиент)

1. Запускает `RemoteConnect.exe`, вкладка **«Подключиться»**.
2. Копирует ваше сообщение целиком и жмёт **«Вставить из буфера»** — адрес и пароль заполнятся сами.
3. Выбирает, что сделать: управлять вашим ПК или разрешить вам управлять своим. Жмёт **«Подключиться»**.
4. На управляемом ПК появится окно **«Разрешить?»** — без нажатия «Разрешить» ничего не начнётся (через 60 с запрос отклоняется сам).

### Во время сессии

- На управляемом ПК вверху экрана — красная плашка с кнопками **«Только просмотр»** (запретить ввод), **«Буфер обмена»**, **«Отключить»** и **«Чат»**.
- **Буфер обмена общий:** текст и картинки, скопированные на одном ПК, можно вставить на другом. Передаётся только то, что скопировано после начала сессии. Выключить синхронизацию можно кнопкой «Буфер обмена» на плашке или в окне просмотра: она работает, только когда включена у обоих.
- **Файлы — тоже через буфер обмена**, как в AnyDesk: скопируйте файлы или папки в Проводнике (Ctrl+C) на одном ПК и вставьте (Ctrl+V) в Проводнике на другом. Файлы передаются в момент вставки, Windows показывает своё окно копирования с прогрессом и кнопкой «Отмена». Пока файлы забирают, на стороне, где их скопировали, видно «Передача файлов: имя, %». Лимит — 500 МБ и 10 000 файлов за одно копирование.
- У управляющего — окно с экраном: полный экран, выбор монитора, качество изображения, «Отключить», «Чат». Пока окно активно, все клавиши (включая Win и Alt+Tab) уходят на удалённый ПК; чтобы вернуться к своему, кликните мимо окна.
- **Качество изображения подстраивается под соединение:** на медленном интернете картинка проще, но не отстаёт от действий; в локальной сети — чёткая и до 30 кадров/с. Когда изображение перестаёт меняться, оно за секунду становится чётким. В окне просмотра можно выбрать «Лучшее качество» (чётче, но может отставать) или «Быстрее» (плавнее, но проще); текущее качество видно в строке статистики.
- **Чат:** кнопка «Чат» справа вверху окна просмотра или на плашке открывает панель переписки. Enter — отправить, Shift+Enter — новая строка; ссылки `http(s)://` открываются по клику в браузере своего ПК. Пока курсор в поле чата, клавиши остаются у вас и на удалённый ПК не уходят — кликните по экрану, чтобы снова управлять. О новом сообщении в свёрнутую панель говорит красная точка на кнопке; у управляемого первое сообщение само раскрывает панель (не забирая фокус). Переписка нигде не сохраняется и исчезает после конца сессии.
- Если что-то не работает — журнал лежит в `%LOCALAPPDATA%\RemoteConnect\logs`.

### Безопасность

- Трафик шифруется TLS (1.3 на Windows 11, 1.2 на Windows 10). Пароль по сети не передаётся.
- 5 неверных паролей с одного IP — блокировка на 5 минут; на вкладке «Хост» её можно снять вручную.
- Если за 30 минут никто не подключился, ожидание останавливается и порт на роутере закрывается.
- «Код хоста» — отпечаток сертификата. Клиент запоминает его и предупредит, если он изменится.

## Ограничения

- Только Windows 10/11 x64.
- Нет звука. Файлы передаются только через буфер обмена, не больше 500 МБ за раз. Вставлять их нужно в Проводник или в программу, которая понимает «виртуальные файлы» (почта, многие файловые менеджеры); программам, которым нужен настоящий путь к файлу на диске, такая вставка может не подойти.
- Обе стороны должны использовать одну версию (v0.5 несовместима с v0.4 и более ранними). Версия написана внизу главного окна; при несовпадении обе стороны v0.4+ увидят номер версии собеседника.
- Экран входа в Windows, окна UAC и Ctrl+Alt+Del недоступны. Окна, запущенные от администратора, не принимают ввод — для этого на управляемом ПК: «Хост» → «Дополнительно» → «Перезапустить от администратора».
- Если ни у кого из двоих нельзя открыть порт (оба за CGNAT), поможет Tailscale/ZeroTier: подключайтесь по их локальному адресу.

## Сборка из исходников

Нужен .NET SDK 10.

```powershell
dotnet test RemoteConnect.sln              # тесты
powershell -ExecutionPolicy Bypass -File .\publish.ps1   # тесты + publish\RemoteConnect.exe
```

Структура:

```
src/RemoteConnect.Core      протокол, TLS, авторизация, логика сессии, передача файлов — без зависимостей от Windows
src/RemoteConnect.Windows   захват экрана, JPEG, SendInput, UPnP, DPAPI, сертификат, виртуальные файлы (OLE)
src/RemoteConnect.App       WPF-интерфейс
tests/                      xUnit: юнит-тесты и интеграционные (TLS по loopback, захват, реальный ввод)
```
